# 60-Day Execution Roadmap — baseline 2026-08-21

This is phase logic, not a rigid day-by-day content list — the master prompt is explicit that daily tasks should come from data and audit findings, not a pre-written publishing schedule. Each "Do today's tasks" session picks from the current phase's backlog based on what's actually done and what GSC/GA4/Bing show.

## Phase 1 — Days 1-10: Foundation & measurement
Cannot make data-driven decisions until this closes.
- Verify Search Console, submit sitemap
- Verify Bing Webmaster Tools
- Confirm/adjust the two primary keyword targets with the user
- Run Rich Results Test across all schema-bearing pages
- Baseline PageSpeed / Core Web Vitals on homepage + top 3 service pages
- Audit canonicals and Open Graph tags site-wide
- Answer the open service-scope question in `00-audit.md` (which services are real)
- Add BreadcrumbList schema and Article/BlogPosting schema to the existing blog post

## Phase 2 — Days 11-25: Pillar depth
- Deepen the two primary pillar pages (roofing-marketing-agency, roofing-lead-generation) with the content-architecture checklist from the master prompt (process, deliverables, FAQs, internal links)
- Publish first blog cluster batch under each of the 7 pillars (see `03-topical-map.md`) — quality-gated, not quota-gated
- Internal link every new post to its pillar + at least one case study
- Start logging any early GSC query data into `04-keyword-database.md`

## Phase 3 — Days 26-40: Location + GEO
- Build Tier 1 location pages one at a time (Houston → DFW → Miami → Tampa/Orlando), each meeting the differentiation bar in `02-location-strategy.md`
- Expand GEO-specific content: direct Q&A formatting pass on top pages, comparison content ("X vs Y")
- Monthly AI-visibility check: manually query ChatGPT/Perplexity/Gemini/Google AI Overviews with the primary + supporting terms, log whether Roofers Growths is cited

## Phase 4 — Days 41-55: Authority + backlinks
- Directory listings (Clutch, DesignRush, UpCity, Sortlist)
- Outreach for 2-5 backlinks/citations per month pace
- Tier 2 location pages if Tier 1 shows movement
- Second blog cluster batch based on which Phase 2 posts actually gained impressions

## Phase 5 — Days 56-60: Review & re-plan
- Full data pull: GSC clicks/impressions/position movement on the two primary keywords, GA4 organic landing-page performance, Bing performance
- Write a plain report: what moved, what didn't, why
- Re-plan the next 60 days based on real data instead of the initial baseline assumptions in this document

## Non-negotiables throughout (repeated from the master prompt, not optional)
No thin location pages. No duplicate city-page paragraphs. No keyword stuffing. No fabricated stats or case studies. No guaranteed-ranking claims. Every new page gets a real internal link in from an existing page.
